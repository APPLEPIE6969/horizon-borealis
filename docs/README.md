# Documentation

This repository delivers the **Borealis shader pack**
([`crates/horizon-shader-api/packs/borealis`](../crates/horizon-shader-api/packs/borealis/README.md))
together with the Horizon workspace it is validated inside. Most of the
upstream Horizon documentation was removed here; what remains falls into two
groups:

**Shader-pack documentation**

- [`api/shaders.md`](api/shaders.md) — the shader-pack format and how the game runs it
- [`api/shaders-reference.md`](api/shaders-reference.md) — the full pack-format reference
- [`shaders.md`](shaders.md) — the render pipeline stages the packs plug into

scripts open these by path, so they are kept even though they describe the
